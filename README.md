# Ground Truth NYC

Responsive event website inspired by the official flyer, with animated skyline, three interactive agent personas, accessible tabs, FAQs, calendar download, and Luma registration links. No API keys, database, or paid runtime services required. Persona examples are illustrative challenge ideas, not live AI agents.

## Run

`npm run dev` serves http://127.0.0.1:3000.

`npm run build` generates the standalone production site in `dist/`.

## Deploy to Vercel

From this directory, run `npx vercel login`, then `npx vercel --prod`. Select your personal Hobby account for free hosting; do not enable paid services. The included vercel.json defines the build and output directory. Alternatively import this directory as a Vercel project using framework Other.

## Content

Event source: https://luma.com/live-agents-hack-nyc (checked October 28, 2026). Event: November 14, 2026, 09:00–18:00 America/New_York. Exact venue, final agenda, judging panel and content prize are not yet published. Registration and host approval stay on Luma.

The page uses Google Fonts with local fallbacks. Set an absolute production og:image URL after a domain is assigned for the broadest social preview support.
